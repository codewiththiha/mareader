## 0.5.0

### Library

- A "recent books" shelf replaces the bare open prompt: every opened PDF is
  remembered with its last-reached page, so reopening resumes where you left
  off. Covers are rendered from the first page; books can be removed from the
  shelf; the list is capped at 20 and persisted separately from appearance
  settings.

### Reading

- Copy/paste and drag-selection now follow visual reading order: out-of-order
  font runs (italics, bold, list numbers, caption labels) are reordered at
  layer-build time, so pasted text is no longer scrambled and a single drag
  paints one contiguous highlight.
- Selection is scoped to the glyph spans: dragging over blank space, margins,
  or the gap between pages can no longer re-anchor the selection to the top of
  the page or paint the whole-page tint wash.
- Fixed a hang where reopening a scrolled document could stall on "Opening…".

### Interface

- A themed drag-and-drop overlay appears while a file is dragged over the
  window (following the active base mode and tint), and the sidebar toggle is
  hidden on the home screen where there is nothing to show.
