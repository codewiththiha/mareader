# Mareader 0.0.7

Mareader brings unified dictionary and AI word cards, a searchable AI model
picker with cleaner provider defaults, smoother live theme and paper-blend
transitions without animation hitches, and flicker-free voice switching in
Settings › Read Aloud.

## What's new

- **Unified Lookup and AI word cards.** Offline dictionary lookups and AI
  contextual explanations now share a clean card header with the headword,
  part of speech, colour-matched CEFR level badge, IPA pronunciation, and
  pronunciation audio button. When both dictionary and AI answers are
  available, an in-place **Dictionary | AI in context** tab switcher lets you
  flip between them without moving the card, alongside compact `EN ⇄ FR`
  language swapping, `< 1 of N >` numeric entry paging (`←`/`→` keys),
  pinned footer actions (`+ Word list`, `Copy`, `Open in the Dictionary`,
  `Ask again`), and clearer empty-dictionary actions.
- **Searchable AI model picker and cleaner provider setup.** In Settings ›
  AI, typing in the Model field now opens a unified autocomplete dropdown with
  full keyboard navigation (`↑`, `↓`, `Enter`, `Esc`), and **Choose** focuses
  the input directly. Built-in providers now default to **Use default
  address**, keeping endpoint URLs tucked away unless you opt to customize
  them.
- **Animated checkboxes and streamlined Vocabulary shading.** Checkboxes
  across Settings and menus now animate smoothly, and Vocabulary shading
  presents **Mark** (`Highlight`, `Half highlight`, `Underline`) and
  **Colour** directly without redundant style selectors.
- **Zero-stall live theme and paper-blend fades.** Switching base modes,
  themes, film grain, or Paper blend now blends UI tokens and GPU page passes
  live instead of blocking on a full-window screenshot readback, and settings
  persistence runs off the UI thread so animations never hitch or skip.

## Fixes

- Eliminated Settings › Read Aloud modal flicker and layout jumps when
  switching between voice models, and reused idle OS speech handles so
  toggling to and from system voices stays responsive.
- Hovering a word card into AI explanations now tracks scroll cleanly without
  leaving stale loading captions or duplicate in-flight requests.
- Kept the read-aloud player strictly along the bottom edge, tucking cleanly
  below popups rather than jumping upward.
- Opening any menu or popover automatically closes the floating Find bar, and
  opening Find dismisses open popovers.
- Kept custom window control icons on Windows and Linux steady on hover, and
  aligned the API key input and **Add** button spacing in Settings › AI.

## Which file to download

| System | File | Install |
| --- | --- | --- |
| macOS 11 or later, Apple Silicon | `Mareader_0.0.7_aarch64.dmg` | open it and drag Mareader to Applications |
| macOS 11 or later, Intel | `Mareader_0.0.7_x64.dmg` | the same |
| Windows 10 or 11 (x64) | `mareader_0.0.7_x64-setup.exe` | run it; it installs for you alone, no administrator needed |

| Debian, Ubuntu, Mint, Pop!_OS (x86_64) | `mareader_0.0.7_amd64.deb` | `sudo apt install ./mareader_0.0.7_amd64.deb` |
| Debian, Ubuntu, Raspberry Pi OS (ARM64) | `mareader_0.0.7_arm64.deb` | `sudo apt install ./mareader_0.0.7_arm64.deb` |
| Arch and its family (x86_64 & ARM64) | `mareader_0.0.7_x86_64.tar.gz` or `mareader_0.0.7_aarch64.tar.gz` with `PKGBUILD` | put your archive and `PKGBUILD` in one folder, then `makepkg -si` |

Installing over v0.0.6 keeps your existing settings, session, library, and
highlights automatically. `SHA256SUMS` lists every file's checksum:
`sha256sum -c SHA256SUMS --ignore-missing` on Linux,
`shasum -a 256 -c SHA256SUMS --ignore-missing` on macOS.

## The first launch

This build is not signed by Apple or Microsoft yet, so each system asks once:

- **macOS:** "Apple could not verify Mareader". Choose Done, then open System
  Settings › Privacy & Security and choose Open Anyway next to Mareader. Later
  launches open directly.
- **Windows:** "Windows protected your PC". Choose More info, then Run anyway.
- **Linux:** nothing to approve. The AppImage only needs to be executable.

## Known limits

- Neural voices are downloads of 24 MB to 327 MB each. System voices need
  none. On Linux, system voices go through Speech Dispatcher.
- Only Kokoro, Piper, and Kitten report exact word timing. With Phonon and
  system voices the lit word follows the reading pace, so it can run slightly
  ahead or behind.
- Skipping tables, lists, figures, and asides works in EPUB, Markdown, and
  plain-text books, not PDFs.
- Windows on ARM64 currently ships as the NSIS installer (`-setup.exe`);
  `.msi` packages remain x64-only.
- Your library stays on this computer; syncing between machines remains future
  work.

Before publishing, CI built every installer on its own native platform (all
six runners), installed each one, verified its binary architecture, opened a
book with it, and removed it again.
