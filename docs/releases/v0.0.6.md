# Mareader 0.0.6

Mareader now ships native ARM64 builds for Windows and Linux, checks for
updates in-app with silent background updates on Windows and Linux AppImage,
opens large EPUBs progressively with instant reflow, and brings a redesigned
Appearance popover, animated icons, and a command palette.

## Summary

### New
- Native installers for Windows on ARM and ARM64 Linux (Debian/Ubuntu, AppImage, and Arch).
- Built-in update checks with silent background updates on Windows and Linux AppImage.
- Progressive EPUB opening and instant reflow when resizing panes or changing typography.
- Redesigned Appearance dial popover, animated icons, command palette, and eight offline dictionary packs.

## What's new

- **Windows on ARM and ARM64 Linux.** Native `aarch64` builds now join x86_64
  and Apple Silicon: an ARM64 Windows setup installer plus ARM64 `.deb`,
  AppImage, and Arch Linux packages, each built and launch-tested on native
  ARM64 hardware in CI.
- **Built-in updates.** Mareader checks GitHub Releases against verified
  SHA-256 checksums, surfaces concise release highlights in a startup update
  modal, and adds Settings › Updates controls. Writable Windows NSIS installs
  and Linux AppImages can download and apply updates silently in the
  background; macOS and package-managed installs open the matching download
  link directly.
- **Progressive EPUB opening and instant reflow.** Large EPUBs open right away
  around your saved reading place while remaining chapters paginate in the
  background, and local typography or pane-width edits retypeset immediately.
- **Appearance dial popover and animated icons.** Appearance controls now live
  in a tactile Dial deck popover with vertical-drag knobs, subtle animated
  semantic icons (toggleable in Settings), voice engine marks, and optional
  edge tabs for peeking floats.
- **Command palette and headless automation.** Press `⌘K` / `Ctrl+K` to search
  and run reader commands from the keyboard. Underneath, Mareader's reader
  engine now powers atomic `settings.json` / `session.json` persistence, a
  zero-UI CLI, and a live control channel.
- **Richer EPUB layout and picture theming.** Improved CSS colour, z-order,
  multi-column, spanning-float, and cover handling, plus consistent
  `theme_pictures` styling across reflow pages, fixed-layout spreads, and
  thumbnails.
- **Eight offline dictionary packs.** Settings › Dictionary now offers eight
  downloadable Wiktionary packs with folded views for packs you haven't
  installed yet, Japanese headword pronunciation in a Japanese voice, and
  smarter parking between the dictionary card and read-aloud player.
- **Lower memory use.** Streamed EPUB cover loading, cached PDF render
  sessions across tiles, streamed Kokoro weights, zero-allocation search
  scanning, and reused GPU buffers reduce peak memory across reading and
  narration.

## Fixes

- Progressive EPUB growth keeps the current reading position steady and avoids
  highlight or frame flicker while resting text caches cleanly.
- Dim mode restores dark book ink so dimmed pages stay calm and readable.
- Toast notifications harmonise their semantic colours with the active theme,
  stack cleanly, and step aside for the dictionary window and menus.
- Hovering or rapidly clicking toolbar icons preserves their active tint and
  completes animations smoothly.
- Spread view highlights both visible pages in the Thumbnails sidebar.
- Fold and selection sidelines are removed for a cleaner reading surface, and
  centralized layer ordering keeps popovers, modals, and toasts cleanly
  stacked.
- On macOS, traffic-light window buttons stay aligned during animated resizes
  with breathing room beside the sidebar icons.
- Erasing reading progress now resets currently open books immediately.

## Which file to download

| System | File | Install |
| --- | --- | --- |
| macOS 11 or later, Apple Silicon | `Mareader_0.0.6_aarch64.dmg` | open it and drag Mareader to Applications |
| macOS 11 or later, Intel | `Mareader_0.0.6_x64.dmg` | the same |
| Windows 10 or 11 (x64) | `mareader_0.0.6_x64-setup.exe` | run it; it installs for you alone, no administrator needed |
| Windows 10 or 11 (x64, managed machines) | `mareader_0.0.6_x64_en-US.msi` | `msiexec /i` it, or deploy it as usual |
| Windows 11 on ARM (ARM64) | `mareader_0.0.6_arm64-setup.exe` | run it; installs native ARM64 Mareader for you alone |
| Debian, Ubuntu, Mint, Pop!_OS (x86_64) | `mareader_0.0.6_amd64.deb` | `sudo apt install ./mareader_0.0.6_amd64.deb` |
| Debian, Ubuntu, Raspberry Pi OS (ARM64) | `mareader_0.0.6_arm64.deb` | `sudo apt install ./mareader_0.0.6_arm64.deb` |
| Arch and its family (x86_64 & ARM64) | `mareader_0.0.6_x86_64.tar.gz` or `mareader_0.0.6_aarch64.tar.gz` with `PKGBUILD` | put your archive and `PKGBUILD` in one folder, then `makepkg -si` |
| Any other Linux, x86_64 (glibc 2.35+) | `mareader_0.0.6_x86_64.AppImage` | `chmod +x` it, then run it |
| Any other Linux, ARM64 (glibc 2.35+) | `mareader_0.0.6_aarch64.AppImage` | `chmod +x` it, then run it |

Installing over v0.0.5 imports your existing settings, session, library, and
highlights automatically on first launch. `SHA256SUMS` lists every file's
checksum: `sha256sum -c SHA256SUMS --ignore-missing` on Linux,
`shasum -a 256 -c SHA256SUMS --ignore-missing` on macOS.

## The first launch

This build is not signed by Apple or Microsoft yet, so each system asks once:

- **macOS:** "Apple could not verify Mareader". Choose Done, then open System
  Settings › Privacy & Security and choose Open Anyway next to Mareader. Later
  launches open directly.
- **Windows:** "Windows protected your PC". Choose More info, then Run anyway.
- **Linux:** nothing to approve. The AppImage only needs to be executable.

## Known limits

- Neural voices are downloads of 24 MB to 327 MB each. System voices need
  none. On Linux, system voices go through Speech Dispatcher.
- Only Kokoro, Piper, and Kitten report exact word timing. With Phonon and
  system voices the lit word follows the reading pace, so it can run slightly
  ahead or behind.
- Skipping tables, lists, figures, and asides works in EPUB, Markdown, and
  plain-text books, not PDFs.
- Windows on ARM64 currently ships as the NSIS installer (`-setup.exe`);
  `.msi` packages remain x64-only.
- Your library stays on this computer; syncing between machines remains future
  work.

Before publishing, CI built every installer on its own native platform (all
six runners), installed each one, verified its binary architecture, opened a
book with it, and removed it again.
