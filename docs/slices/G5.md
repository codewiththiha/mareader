# G5 — the second client (`apps/mareader-cli`)

Branch: `feat/engine-g5-cli`, from `feat/engine-g4-host` at `386daed`. Review
phase: **P5** (*Ship the second client*).

This slice ships `apps/mareader-cli`, an L7 headless client implementing
`engine::Host` over `std` with zero toolkit crates in its dependency tree,
exposing the four verbs (`commands`, `exec`, `run`, `inspect`) and proving
every core reading workflow headlessly in CI with no display and no GPU.

G5 touches none of `AGENTS.md`, `parity/mareader-features.toml`, or
`ROADMAP.md` (reserved for G6).

---

## Deliverables

### 1. Engine scriptability & headless lifecycle (`c46551c`)

Small additions to `crates/engine` so all five CLI workflows run 100% through
`Session::execute_id` with zero new `Command` enum variants (`SPECS` stays 66
rows on native / 64 on wasm):

- `Session::busy(&self) -> bool` (`crates/engine/src/session/tick.rs`),
  combining `documents.opening()`, `library.loading()`, active library runs,
  `search.busy()`, `word_lists.busy()`, `page_copy.busy()`, and
  `vocab.coming()`.
- `Session::set_progressive_open(&mut self, on: bool)`
  (`crates/engine/src/documents/state.rs`, `session/documents.rs`) so headless
  clients open multi-chapter EPUBs whole without waiting for a rasterized
  preview page (GUI default stays `true`; L0–L3 crates stay unchanged).
- `Session::last_document(&self)` / `Session::last_document_with(...)`
  (`crates/engine/src/session/documents.rs`), shared with
  `MareaderApp::last_document`.
- `Session::latest_mark` and `Session::export_notes`
  (`crates/engine/src/session/study.rs`), wired into `command_spec`:
  - `study.act` adds `"set_note"` (`StudyAction::SetNote`), defaulting `mark`
    to the latest highlight on the active pane when omitted.
  - `library.act` adds `"import_folder"` (`LibraryAction::ImportFolder`),
    accepting `root` and optional `min_size`, `in_place`, `watch`, `groups`.
  - `export.write` renders the active (or named) pane's highlights and notes
    via `Session::export_notes` when `contents` is omitted, while remaining
    100% backwards-compatible when `name` and `contents` are passed explicitly.
- Updated `crates/engine/tests/forms.rs` to cover all three new script forms.

### 2. Headless client `apps/mareader-cli` (`c775310`)

- Manifest (`apps/mareader-cli/Cargo.toml`): zero new external crates and zero
  toolkit crates (`mareader-engine`, `mareader-workspace`, `serde_json` in
  `[dependencies]`; `mareader-pdf`, `mareader-epub`, `rusqlite`, `tempfile` in
  `[dev-dependencies]`), `[lints] workspace = true`, strict
  `#![deny(clippy::unwrap_used, clippy::expect_used, clippy::panic, clippy::unimplemented, clippy::todo, clippy::unreachable, clippy::indexing_slicing)]`.
- `Cargo.lock` updated in the same commit with only the `mareader-cli`
  workspace entry (preserving CI's `v0-rust-linux` build cache).
- `src/host.rs`: `CliHost` implementing `engine::Host` over `std` plus a
  `Condvar`-backed `Gate` waker.
- `src/driver.rs`: `Runner` driving `Session::new`, resuming saved sessions,
  replaying JSONL scripts (`-` reads stdin, `${VAR}` expands inside JSON
  strings), settling background threads via `Gate` + `pump()` + `tick()`, and
  persisting via `Session::settle`.
- `src/output.rs`: JSON serializers for `SPECS`, full session state
  (`route`, `active`, `panes` with page text/search hits/marks, `library`
  books/shelves/folders, `vocab`, `dict`, `settings`), and drained `Event`s.
- `src/main.rs`: exact four verbs (`commands`, `exec <id> [json]`,
  `run <script.jsonl>`, `inspect`) with `--state-dir <path>` /
  `MAREADER_STATE_DIR`.
- `xtask/src/layers.rs`: added `check_headless_tree` / `headless_tree`,
  running `cargo tree -q --locked --offline -p mareader-cli -e normal,build --prefix none`
  during `cargo xtask layers` to enforce zero transitive toolkit dependencies.

### 3. Five end-to-end headless scripts & CI integration (`888dc82`)

Committed under `apps/mareader-cli/scripts/`:

1. `01-page-text.jsonl` — print page 0 text from a PDF and from an EPUB.
2. `02-search-book.jsonl` — open an EPUB (`the-raven-gutenberg-17192.epub`) and
   search it for `"Nevermore"`.
3. `03-highlight-note-export.jsonl` — select text, highlight it, attach a note,
   and export notes as Markdown.
4. `04-word-list.jsonl` — attach a CEFR vocabulary table and build a word list.
5. `05-import-folder.jsonl` — import a folder of PDF and EPUB books into the
   library, switch to the library view, and verify persistence across
   `inspect`.

Exercised by `apps/mareader-cli/tests/scripts.rs` (7 integration tests
covering `commands`, `exec` + `inspect` persistence, and all 5 scripts with
`DISPLAY` and `WAYLAND_DISPLAY` removed) and wired as an explicit
`Headless CLI scripts` step in `.github/workflows/ci.yml`.
