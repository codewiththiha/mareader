# Split Notes

A short Markdown document the browser suite opens beside a PDF, so one
workspace holds two panes with two different format sessions: a PDF engine
session on one side and a reflowed text stream on the other.

## Why it exists

Closing one pane must leave the other one reading. This file is the other
one: when the PDF beside it closes, these paragraphs are still laid out,
still scrollable and still the active document.

## What it contains

Plain paragraphs, two levels of headings for the outline, and a list:

- a first item,
- a second item,
- a third item.

## The end

Nothing here depends on the PDF next to it.
